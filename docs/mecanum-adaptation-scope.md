# 差速仿真到大型麦轮实车：改动范围

2026-10-10，用户确认实际使用大型摆式悬挂麦轮底盘，扩展板暂定V3，尚待实物核实。

## 已确认的现有实现

- `src/person_follow_description/urdf/follow_bot.urdf.xacro` 使用左右两个驱动轮和 `libgazebo_ros_diff_drive.so`，是两轮差速仿真。
- C++控制的 `Command` 只有前进速度和角速度，监督节点输出 `Twist.linear.x` 与 `Twist.angular.z`；`linear.y`保持消息默认的零值。
- Python视觉包发布人体光学XYZ、可靠性和状态，不依赖车轮类型，可以继续复用。

## 必须完成的底盘适配

| 部分 | 麦轮接入工作 |
|---|---|
| 底盘驱动与车型 | 核对大型配置，四个电机按正确的麦轮运动学分配轮速；不能继续套用两轮差速驱动或原ROS示例写死的车型1 |
| 反馈与里程计 | 保留真实横向速度，修正示例中vy被覆盖为0的问题；判断串口帧新鲜度，初始化首帧积分时间 |
| 停止与启动链 | 确认/补齐输入停发、串口断联及驱动/固件异常的停车能力；保持明确的速度来源，处理默认手柄发布者 |
| 实际坐标与参数 | 使用真实odom、底盘几何及D435i安装TF，退出固定预览的测试TF和零速度odom |
| 对应仿真 | 若继续使用仿真验证麦轮，则另建四轮麦轮模型和与选定控制范围一致的驱动；原差速模型不能代表横移 |

## 两种跟随范围

### 第一版先跑通前进与车身转向

保持 `linear.y=0`，复用已有的1.5米距离保持、转向对准、近处停止前进、失效归零和恢复确认。四个电机依旧由麦轮驱动分配轮速。机器人具有横移能力，但本轮跟随策略暂不使用；底盘独立联调仍应检查横移方向与真实反馈。

这是当前建议的首轮范围。旧差速仿真继续用于已通过的控制逻辑回归；随车相机、底盘反馈和实际制动另行实测。

### 第一版加入全向横移

需要扩展C++控制的横向速度、合成平移速度限制和加速度约束；为前进、横移与转向设计配合规则，保持人位于相机视野内。目标失效或急停时所有速度分量必须归零。真实odom、状态估计和仿真均需覆盖横向运动，再增加横移、组合移动、失效与恢复验收。

这一范围尚未确定。已按一次一个问题询问用户首轮是否启用横移，尚未修改运行代码或改变既有默认参数。

## 版本与执行顺序

扩展板硬件V3、底盘车型编号及固件版本分别核对，不能按硬件V3直接设车型3。协议里的X3PLUS=2及固件的大麦轮定义作为配置核对依据，以实物为准。

先整理/验证驱动与反馈，再接随车D435i和C++跟随；保留差速基线，独立保存麦轮配置与测试结果。跟随距离1.5米、目标0.5秒超时及原始测量时间戳规则沿用。
